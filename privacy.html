Privacy Policy: itsSeewulf Shorts Agent

Effective November 1, 2026

The itsSeewulf Shorts Agent is a private automation tool that I, Prabin Bhusal, built to publish and track Shorts on my own YouTube channel, @itsSeewulf. It is not offered to the public, and I am its only user.

What it accesses

When I sign in with Google, the agent asks for these permissions, and uses them for my own channel only:

  • Upload videos (youtube.upload): to publish each new Short.
  • View my YouTube account (youtube.readonly): to read the view, like and comment counts of my videos.
  • View YouTube Analytics reports (yt-analytics.readonly): to read how much of each video people watch.

How the data is used

  • Video statistics decide which topics to make next.
  • Titles and statistics of my own videos are sent to Anthropic's Claude API to plan and write new scripts. Under Anthropic's commercial terms, API data is not used to train their models.
  • Nothing is sold, shared for advertising, or used to train AI models.
  • No data about any other person is collected.

Where it is stored

  • The Google sign-in token is kept as an encrypted GitHub Actions secret and in a local file on my own computer.
  • Video titles and statistics are kept in my private GitHub repository.

Google API Services

The agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The agent uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from Google Account → Third-party apps & services.
